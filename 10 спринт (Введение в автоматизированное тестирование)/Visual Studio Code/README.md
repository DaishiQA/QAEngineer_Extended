# Тесты на проверку параметра name при создании набора внутри конкретного пользователя с обязательной передачей заголовока Authorization (эндпоинт /api/v1/kits) в Яндекс.Прилавок с помощью API Яндекс.Прилавок.
- Файл data.py содержит тела POST запросов
- Файл configurstion.py содержит URL и пути запросов
- Файл sender_stand_request.py содержит POST Запросы на создание пользователя и создание набора для авторизованного пользователя
- Файл create_kit_name_kit_test.py содержит тесты 
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest
- Перед запуском тестов необходимо добавить адрес тестового сервера в файл configuration.py -> URL_SERVICE = "адрес тестового сервера"
