Тема:
- тест-дизайн
- классы эквивалентности, типы набор и диапазон, разбиение требований на классы эквивалентности
- граничные значения, определение шага и границ
- применение техник классов эквивалентности и граничных значений
- позитивные и негативные проверки
- таблица принятия решений
- попарное тестирование
- диаграмма и таблица состояний и переходов
- выбор техники тест-дизайна
разработка чек-листа, тест-кейсов

Проект:
Работа с новой версией приложения Яндекс Маршруты. Проектирование тестов для функциональности каршеринга.

Задачи:
- проверить корректность валидации данных в форме добавления прав (поля «Имя», «Фамилия», «Дата рождения», «Номер») - выделить классы эквивалентности и граничные значения
- составить диаграмму состояний и переходов между всплывающими окнами
- составить чек-лист проверок на основании диаграммы состояний и переходов
- подготовить таблицу принятия решений и написать тест-кейсы по кнопке «Забронировать»

Инструменты:
- Test IT (https://testit.software/)
- draw.io (https://app.diagrams.net/)
