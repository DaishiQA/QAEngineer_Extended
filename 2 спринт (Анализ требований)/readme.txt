Тема:
- код приложения (переменные, базовые типы данных, условия, массивы и словари, циклы)
- этапы тестирования новой функциональности
- требования (системные, бизнес, пользовательские)
- тест анализ (анализ, декомпозиция, визуализация (диаграмма связей, блок-схема), серые зоны

Проект:
Работа с приложением Яндекс Маршруты. Это интерактивная веб-страница, куда можно добавлять фотографии. Также фотографии можно оценивать лайком и удалять.

Задачи:
- провести анализ требований, создание mindmap по требованиям
- провести анализ требований к новой фиче, создание mindmap изменения функциональности приложения после добавления фичи
- выявить наличие серых зон

Инструменты:
- draw.io (https://app.diagrams.net/)

Результат:
- mindmap по требованиям
- mindmap изменения функциональности приложения
- запрос на уточнение серых зон
